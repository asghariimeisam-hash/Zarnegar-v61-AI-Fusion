# زرنگار v61 — نسخه وب (Web Edition)

زرنگار حالا یک **وب‌اپلیکیشن کامل** است: در مرورگر باز می‌شود، بدون نیاز به Android Studio،
MetaTrader یا مدل‌های سنگین Chronos/TimesFM.

## راه‌اندازی (فقط یک دستور)

```bash
node server.js
```

سپس در مرورگر باز کنید:

```
http://localhost:8000
```

همین. داشبورد، فید قیمت، موتور AI Fusion و بک‌تست همه داخل همین یک فایل (بدون هیچ وابستگی خارجی) اجرا می‌شوند.

## چه چیزهایی اضافه/اصلاح شد

1. **رفع ایراد اجرا در مرورگر** — قبلاً موتور AI و MT5 Bridge فقط داخل WebView اندروید کار می‌کرد و در مرورگر بی‌صدا غیرفعال بود. حالا یک لایه سازگاری (Web Bridge Shim) همان رابط `AndroidBridge` را با `fetch` به بک‌اند وصل می‌کند.
2. **آنلاین شدن** — یک سرور Node (بدون وابستگی) فایل‌ها و API را سرو می‌کند.
3. **موتور هوش مصنوعی پیشرفته** — به‌جای یک شاخص ساده، دو مدل مستقل با هم ادغام می‌شوند:
   - **Trend Fusion** — هم‌جهتی H1/M15 (EMA20/50، EMA9/21/50) + قدرت روند (ADX) + جدایی EMA.
   - **Momentum / Mean-Reversion** — RSI + باند بولینگر + Momentum (ROC) + ساختار قیمت.
   - **Regime Filter** — تشخیص Trend / Range برای جلوگیری از معامله در بازار خنثی.
   - **Consensus Gate** — اگر مدل‌ها اختلاف داشته باشند یا با رژیم هم‌جهت نباشند → `WAIT`.
4. **وین‌ریت واقعی و شفاف** — یک بک‌تستر که همان منطق ورود را روی تاریخچه شبیه‌سازی‌شده اجرا می‌کند و وین‌ریت، Profit Factor و حداکثر Drawdown را **اندازه‌گیری می‌کند** (نه ادعا).

## Endpointها

| مسیر | توضیح |
| --- | --- |
| `GET /` | رابط کاربری |
| `GET /v1/health` | وضعیت پل (فقط خواندنی) |
| `GET /v1/market?symbol=XAUUSD` | قیمت لحظه‌ای Bid/Ask |
| `GET /v1/bars?symbol=XAUUSD&timeframe=M5&count=300` | کندل‌های OHLC |
| `GET /v1/ai?symbol=XAUUSD` | تصمیم AI Fusion |
| `GET /v1/stats` | آمار بک‌تست صادقانه |

## نکته‌های مهم و صادقانه (بخوانید)

- **فید بازار «شبیه‌سازی‌شده» است** — یک مدل رژیم‌سوییچ با خوشه‌بندی نوسان، نه فید واقعی کارگزار. برای فید واقعی همچنان به پل MetaTrader روی ویندوز نیاز دارید.
- **AI Strength احتمال برد نیست.** فقط امتیاز قدرت و هم‌جهتی مدل‌هاست.
- **وین‌ریتِ بک‌تست تضمین عملکرد زنده نیست.** روی داده شبیه‌سازی‌شده محاسبه شده و نتایج گذشته تضمین آینده نیستند.
- **این نسخه READ-ONLY است** و هیچ مسیر `order_send` یا اجرای معامله واقعی ندارد.
- **سودآوری با وین‌ریت بالا یکی نیست.** یک سیستم با وین‌ریت ~۴۵–۵۰٪ و نسبت سود/ضرر ۱٫۵ همچنان سودده است؛ آنچه مهم است مدیریت ریسک (حد ضرر، حجم، فیلتر رژیم) است نه درصد برد بالا.

## تفاوت با نسخه اندروید

نسخه اندروید (APK + پل MetaTrader) دست‌نخورده باقی مانده است. این نسخه وب یک اجرای مستقل و قابل نمایش در مرورگر است و همان معماری Read-Only و همان گیت‌های امنیتی را حفظ می‌کند.
